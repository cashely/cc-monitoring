# Triage 标签

Skills 以五个标准 triage 角色表述。本文件将这些角色映射到本仓库 issue 跟踪中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪中的标签 | 含义                          |
| -------------------------- | ------------------ | ----------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此 issue        |
| `needs-info`               | `needs-info`       | 等待报告者补充更多信息        |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可交给 AFK agent    |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                  |
| `wontfix`                  | `wontfix`          | 不予处理                      |

当某个 skill 提到某个角色时（例如"打上 AFK-ready 的 triage 标签"），使用本表中对应的标签字符串。

如需使用你自己的词汇，修改"本仓库跟踪中的标签"一列即可。
